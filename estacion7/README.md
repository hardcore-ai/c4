# Estación 7: Del backlog al cambio revisable

Esta estación es un taller de implementación. El objetivo es ejecutar una tarea elegible del paquete preparado en estación 6, demostrar el resultado y dejar un PR listo para revisión.

## Material de clase

- [Presentación PDF](estacion7.pdf).
- [Presentación HTML editable](estacion7.html).
- [Tarea de preparación](preparacion.md), también disponible en [PDF](preparacion.pdf).
- [Recursos de estaciones 6 y 7](../estacion6/recursos.md).

## Resultado esperado

- Una tarea e issue alineados, con alcance y aceptación claros.
- Un cambio acotado o un bloqueo documentado con evidencia.
- Validación ejecutada y resultados registrados.
- Un PR abierto o actualizado.
- Una revisión cruzada y el siguiente estado explícito.

El merge no es un requisito de la sesión. Solo corresponde cuando aceptación, pruebas y revisión lo permiten. Si faltan Linear, push o un runner, usa la contingencia del guion y conserva la misma trazabilidad.

Para el instructor: [guion, tiempos y contingencias](fuente/guion.md). `fuente/` contiene material de edición y referencia; el HTML y PDF enlazados arriba son los artefactos finales.
